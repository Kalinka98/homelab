# Security policy

This repository describes a real self-hosted deployment. **Do not attempt to test any running services, infrastructure, or domains mentioned in the configuration without explicit authorization.**

If you identify a vulnerability in configuration published here, please use GitHub's **private vulnerability reporting** feature if enabled, or contact the repository owner privately through their GitHub profile. Do not post credentials, access tokens, private calendar feeds, personal data, or exploit details in public issues.

The sample `.env.example` values are placeholders and must not be used as production credentials. The repository is not a security-hardened distribution of its third-party applications.
